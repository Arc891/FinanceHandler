## ⚠️ Important Notes

### AI Availability in Docker
Currently the Docker container has:
- ❌ No Claude Code CLI
- ❌ No API key configured
- ✅ Only regex matching works

**To enable AI in Docker**, add to your config or environment:
```bash
export CLAUDE_API_KEY="sk-ant-..."
```

Or rebuild Docker image with Claude Code CLI installed (more complex).

### Date Sorting
- **Format**: DD-MM-YYYY (ASN Bank format)
- **Sort order**: Oldest first (ascending by date)
- **Applied to**: Both income and expenses separately
- **Fallback**: Invalid dates sorted to 01-01-1970

### Session Structure
```json
{
  "remaining": [],           // Only low-confidence transactions
  "income": [/* sorted */],  // Stored until upload trigger
  "expenses": [/* sorted */], // Stored until upload trigger
  "auto_categorized": [],    // For /review command
  "cached": [],
  "sheet_positions": {...}
}
```
